# Tsuzu Loom

物語を織る、創作のための設定管理ツール。

人物・集団・場所・用語・章・シーンをひとつの作品としてまとめ、相関図や年表として見渡せます。スマートフォンとパソコンのどちらからでも使えます。

**アプリを開く** https://tsuzuloom.github.io/
**使い方** https://tsuzuloom.github.io/docs/guide.html

登録せずに試せるデモを用意しています。アプリを開き、ログイン画面の「登録せずに試す」からご覧ください。

---

## 主な機能

### 作品独自の暦

月の数も、名前も、日数も自由に決められます。1年が3ヶ月しかない世界でも、1ヶ月が45日ある世界でも作れます。

元号を登録すれば「動乱期3年 芽の月8日」のように表示されます。年の途中での改元にも対応しています。和暦と西暦のように、同じ日を二通りの呼び方で併記することもできます。

日付は内部では「暦のはじめから何日目か」という数字で保持しているため、**元号をまたいでも、月の日数がばらばらでも、年齢が正しく計算されます**。

### 相関図

人物をドラッグして自由に配置できます。配置は保存され、次に開いても同じ並びです。

関係は**向きごとに別々に持てます**。「AはBが好き、BはAが嫌い」を一本の線で表せます。片方だけ設定すれば片想いになります。矢印の向き、線の種類（実線・二重線・点線・ハート・バツ）、それぞれの向きに添える言葉も選べます。

### 人物

- 姓名とふりがな、性別、イメージカラー、画像
- 誕生日・死亡日から、作中の「現在」を基準にした年齢を自動で表示
- 能力値を時期ごとに分けて記録（序盤・現在・覚醒後など）
- 自由項目を自分で作成（身長・口癖・好きなものなど）
- 一覧はリスト・カード・顔の3表示。名前順、生まれた順、自由項目の値でも並べ替え可能

### 章とシーン

章のカードにシーンが積み上がる形で構成を確認できます。シーンには日付・場所・登場人物・脚本を持たせられます。

### 年表

日付が入ったシーンが、作品の暦に沿って並びます。同じ日のシーンは束ねて表示されます。

### 文字数

作品全体、章ごと、シーンごとの文字数。原稿用紙と文庫ページへの換算も表示されます。

### そのほか

- 作品全体を横断する検索
- 全作品共通のアイデアボックス
- テーマ6種類、ダークモード、見出しの書体切り替え
- JSONでのバックアップと復元
- Markdownでの書き出し

## データについて

データはアカウントごとに保管され、他の利用者からは見えません。同じメールアドレスでログインすれば、どの端末からでも同じ内容を編集できます。

万一に備えて、定期的なバックアップをおすすめします。

**その他 → 作品の設定 → JSONでバックアップ**

書き出したファイルは、同じ画面の「JSONを復元」から読み込めます。

くわしい手順は[使い方](https://tsuzuloom.github.io/docs/guide.html)をご覧ください。
